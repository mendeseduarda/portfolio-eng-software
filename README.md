# Portfólio Pessoal

Este projeto consiste no desenvolvimento de um portfólio pessoal, criado como atividade da disciplina de **Engenharia de Software**, no curso de Ciência da Computação, durante o ano de **2026**.

O objetivo do projeto é aplicar conceitos de desenvolvimento e organização de software trabalhados durante a disciplina.

## Tecnologias

O projeto foi desenvolvido utilizando:

- HTML
- CSS
- Git e GitHub
- GitHub Pages

## Acesso

O portfólio está publicado utilizando **GitHub Pages** e pode ser acessado em:

> [https://mendeseduarda.github.io/portfolio-eng-software/]
